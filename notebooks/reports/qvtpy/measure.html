Part A — 4D-flow hemodynamics (PITC / PWV, stage 6)

A.1 Velocity from PC-MRI phases

Phase images (AP, RL, FH) are converted to velocity components (mm/s):

\[ v_x = -10 \cdot \text{RL},\quad v_y = -10 \cdot \text{AP},\quad v_z = 10 \cdot \text{FH} \]

Code: velocity_mm_s_from_phases() — src/nvitk/measure/hemodynamics.py

A.2 Cross-section at a centerline station

At station \(\mathbf{p}\) with unit tangent \(\hat{\mathbf{t}}\):

  1. 1. Build an oblique plane (default radius \(R = 10\) vox).
  2. 2. Reslice MAG, CD, VEL (and optionally seg_4dflow label).
  3. 3. Resegmentation (PITC default on): fuse channels with weights \((0.2, 0.8, 0.2)\), apply sliding threshold (lsthr), keep the connected component nearest the plane center; optionally intersect with the vessel label mask (--pitc-label-constrain, default on).
  4. 4. Area (mm²): pixel count × tilt-corrected pixel area on the plane grid.
  5. 5. Circularity proxy (used in quality):
\[ C = \left(\frac{R_{\text{in}}}{R_{\text{out}}}\right)^2 \]

where \(R_{\text{in}} = \max\) EDT inside mask, \(R_{\text{out}} = \max\) distance from mask centroid to boundary.

  1. 6. Through-plane velocity at frame \(t\):
\[ v_{\perp}(t) = \frac{1}{|\mathcal{M}|}\sum_{(i,j)\in\mathcal{M}} \mathbf{v}(i,j,t)\cdot\hat{\mathbf{t}} \]
  1. 7. Flow time series (ml/s):
\[ Q(t) = v_{\perp}(t)\cdot\frac{A_{\text{mm}^2}}{1000} \]

A.3 Pulsatility index (PI)

For PITC stations, on signed flow:

\[ \text{PI} = \frac{|\max_t Q(t) - \min_t Q(t)|}{\overline{Q}} \]

where \(\overline{Q} = \text{mean}(Q(t))\) (signed mean, not \(|\cdot|\)).

Code: pulsatility_index_qvt() → pitc_profile.csv column pi.

Note: The LOC track uses pulsatility_index() with \(\text{mean}(|Q|)\) in the denominator — different from PITC PI.

A.4 StdvFromMean quality (default, 0–4 scale)

For station \(m\) along a branch, define a local window of neighboring stations (MATLAB paramMap_params_threshS windowing via branch_window_slices()).

Over window \(\mathcal{W}_m\), with per-cycle mean flows \(Q^{\text{cycle}}\), areas \(A\), circularities \(D\), and full pulsatile matrix \(Q(t)\):

\[ \begin{aligned} qv_{\text{meanflow}} &= 1 - \frac{\text{std}(Q^{\text{cycle}})}{|\text{mean}(Q^{\text{cycle}})|} \\ qv_{\text{area}} &= 1 - \frac{\text{std}(A)}{|\text{mean}(A)|} \\ qv_{\text{circ}} &= \text{mean}(D) \\ qv_{\text{tight}} &= 1 - \frac{\text{mean}_t(\max_s Q - \min_s Q)}{|\text{mean}(Q^{\text{cycle}})|} \end{aligned} \] \[ Q_{\text{quality},m} = qv_{\text{meanflow}} + qv_{\text{area}} + qv_{\text{circ}} + qv_{\text{tight}} \]

Alternative (waveform metric): roughness of second temporal difference relative to amplitude, mapped to 0–4.

Code: stdv_from_mean_branch() / stdv_from_mean_station() in hemodynamics.py; assigned in _assign_branch_qualities().

A.5 Distance along the arterial tree

Three root regions (label-aware tree):

RootVessels
L_ICALICA, LACA, LMCA
R_ICARICA, RACA, RMCA
BasilarBasilar, LPCA, RPCA, LVA, RVA

Communicating arteries are excluded. PCAs belong under Basilar only.

Arc length along polyline \(\{\mathbf{p}_k\}\) with anisotropic spacing \(\mathbf{s}\):

\[ d_k = \sum_{j=1}^{k} \|\,(\mathbf{p}_j-\mathbf{p}_{j-1})\odot\mathbf{s}\,\|_2 \]

Branch stations add root arc length at the junction plus Euclidean gap between root distal and branch proximal endpoints. Proximal = inferior (min-\(z\)) endpoint.

Code: _arc_length_mm(), _orient_polyline(), _root_proximal_anchor() in vessel_hemodynamics.py.

A.6 PITC (Pulsatility Index Transmission Coefficient)

For root region \(r\), collect stations \(\{(\text{PI}_i, d_i, Q_i)\}_{i\in\mathcal{S}}\).

Inclusion weights (Dempsey-style, threshold \(\tau=2.5\)):

\[ w_i = \max\left(0,\ \frac{Q_i - \tau}{4 - \tau}\right) \]

Keep stations with \(w_i > 0\); require ≥2 points.

Weighted linear regression:

\[ \text{PI}(d) = p_{\text{tc}}\,d + \beta \]

Outputs: pitc_slope (\(p_{\text{tc}}\), 1/mm), pitc_intercept (\(\beta\)), r2, global_pi.

Code: quality_weights(), weighted_linear_fit(), pitc_fit() in hemodynamics.py; per ROOT_GROUPS in compute_vessel_hemodynamics().

A.7 Damping index (per branch)

\[ p_d = \frac{\text{PI}_{\text{prox}} - \text{PI}_{\text{dist}}}{\text{PI}_{\text{prox}}} \]

Code: damping_index() in hemodynamics.py.

A.8 PWV — cardiac frame duration, stations, and weights

PWV is computed per root region (L_ICA, R_ICA, Basilar) over dense cross-section stations ordered by arc length from the proximal root (see A.5). Both Fielding and Bjornfoot use the same station pool. Primary CSV outputs match QVTplus enc_PWV.m indices 1–2: Bjornfoot and Fielding with area/scaling² weights (tag=0). The PWV figure also shows a second Fielding fit with Dempsey quality weights \(W_2\) (tag=1), matching QVTplus dual-weight plots.

Cardiac frame duration \(\Delta t\). PESA / Q-flow volumes store a fixed number of frames (typically 15) that are RR-normalized: they always span one cardiac cycle, not a fixed MRI clock. Therefore

\[ \Delta t = \frac{\mathrm{RR}}{n_{\mathrm{phases}}} = \frac{60/\mathrm{HR}}{n_{\mathrm{phases}}} \]

Stage 6 resolves \(\Delta t\) from DICOM HeartRate and the phase count in the volume (priority), or NominalInterval / n_phases, or FrameTime only as a last resort. NIfTI t_res / pixdim[4] and DICOM RepetitionTime are not used — they reflect MRI RF timing (~5 ms), not cardiac phase spacing (~50–100 ms).

Station inclusion. Only stations with quality \(Q_i > \tau\) (default \(\tau = 2.5\)) enter the PWV calculation; at least 3 such stations are required.

Two weight schemes (QVTplus enc_PWV / enc_PWV_XCor tags 0 and 1):

  1. \(W_1\) — Bjornfoot area weights (bjornfoot_prepare_waveforms, tag=0 / QVTplus enc_PWV_WO): convert flow→velocity \(v_i = Q_i/A_i\); zero-mean / unit-std normalize; \(A_i \leftarrow A_i / \mathrm{scaling}_i^2\) with \(\mathrm{scaling}=1/\mathrm{std}(v)\); \(W_{1,i} = A_i / \max_j A_j\). Used for primary CSV Bjornfoot and Fielding (pwv_bjornfoot_m_s, pwv_fielding_m_s).
  2. \(W_2\) — Dempsey quality weights (tag=1): \[ W_{2,i} = \max\left(0,\ \frac{Q_i - \tau}{4 - \tau}\right) \] Used on the PWV diagnostic figure (second fit line) to match QVTplus dual-weight plots; not the primary CSV Fielding column.

Outputs. Values are written only if they pass accept_pwv(): \(0 < \mathrm{PWV} < 30\) m/s (MATLAB sets PWV = 0 if result \(\geq 30\)). Otherwise pwv_fielding_m_s / pwv_bjornfoot_m_s are left empty while diagnostics (e.g. pwv_r_fielding, pwv_n_stations) may still be populated. DB maps pwv_bjornfoot_m_s → variable pwv.

Code: _cardiac_frame_duration_s(), _phase_temporal_resolution_s() in stage6_measure.py; _root_pwv(), bjornfoot_prepare_waveforms(), quality_weights() in vessel / hemodynamics modules.

A.9 PWV — Fielding cross-correlation

For \(n\) stations with distances \(d_i\) (meters) and flow matrix \(Q_{i,t}\) (ml/s over one cardiac cycle), Fielding estimates PWV from how arrival delay grows with distance along the vessel (QVTplus enc_PWV_XCor / Rivera-style).

Intuition. If a pulse propagates steadily from proximal to distal, waveforms at farther stations should arrive later. Plotting transit delay \(\tau_i\) vs distance \(d_i\) should be approximately linear; the slope gives \(1/\mathrm{PWV}\).

  1. Reference. The most proximal included station (index 0 after sorting by \(d_i\)) is the reference waveform \(Q_{\mathrm{ref}}(t)\).
  2. Normalization. Each waveform is zero-mean, unit-standard-deviation before correlation, so delay depends on shape rather than absolute flow magnitude.
  3. Spline upsampling. Each periodic cycle is upsampled with a cubic spline on a tripled trace (upsample_periodic_cycle(), default 500 samples per cycle).
  4. Circular cross-correlation. On the upsampled traces, circular_cross_correlation_lag() finds the lag \(\ell_i\) (wrapped to \((-n/2, n/2]\)) that maximizes correlation with the reference. Delays are converted to seconds via cross_correlation_delay_seconds(): \[ \tau_i = -\frac{\ell_i}{s_{\mathrm{pp}}}\,\Delta t \] where \(s_{\mathrm{pp}}\) is samples-per-original-frame after upsampling. Positive \(\tau_i\) means station \(i\) arrives later than the reference (distal later than proximal).
  5. Weighted linear fit. Primary CSV Fielding fits \(\tau_i = a\,d_i + b\) with \(W_1\) area weights (QVTplus tag=0 / PWV index 2). The diagnostic figure also overlays a \(W_2\) Dempsey-quality-weighted fit (tag=1 / PWV index 4). Slope \(a\) has units s/m: \[ \mathrm{PWV}_{\mathrm{Fielding}} = \frac{1}{a}\quad\text{(m/s)}. \]
  6. Outlier rejection. When ≥4 stations remain, MAD-based robust outlier masking (_mad_outlier_mask, \(z \leq 3.5\)) is applied to \(\tau_i\) before the fit (QVTplus isoutlier analogue).

Acceptance and diagnostics.

  • Requires ≥3 high-quality stations at the root level; the fit itself needs ≥2 valid points after masking.
  • CSV value accepted only if \(0 < \mathrm{PWV} < 30\) m/s (accept_pwv()).
  • pwv_r_fielding stores the mean absolute cross-correlation over included stations (QC, not a velocity).

Code: upsample_periodic_cycle(), circular_cross_correlation_lag(), cross_correlation_delay_seconds(), pwv_fielding_xcor() in hemodynamics.py.

A.10 PWV — Bjornfoot optimizer (QVTplus joint fit)

Bjornfoot (J Cereb Blood Flow Metab 2021) is ported from QVTplus enc_PWV_WO.m + PWVest3_share.m. Unlike a scalar PWV-only search, it jointly fits a shared velocity template (one sample per cardiac frame) and PWV by weighted least squares.

Intuition. There is one unknown “underlying” pulse shape. For a trial PWV, that template is time-shifted to each station by \(\Delta t_i = d_i / \mathrm{PWV}\) and compared to the observed (normalized) waveforms. The optimizer finds the template and PWV that minimize the weighted squared residual.

Preprocessing — see A.8 (bjornfoot_prepare_waveforms): velocity-normalized waveforms \(F\) and area weights \(W\).

Cost (pwvest3_share_cost / residuals, matching PWVest3_share.m):

  1. Let \(\mathbf{v}\) be the template (length \(m\) = number of cardiac frames) and \(\mathrm{PWV}\) the last parameter.
  2. Triple the template on the time axis: \(t_V = 0, \Delta t, \ldots, 3m\Delta t - \Delta t\).
  3. At each station \(i\), evaluate the template at \(t - d_i/\mathrm{PWV}\) by linear interpolation (interp1 analogue), then keep the middle cycle (samples \(m+1 \ldots 2m\)).
  4. Cost \(= \sum_{i,t} W_i \bigl(v_{\mathrm{shift},i}(t) - F_i(t)\bigr)^2\) (paper ML / weighted least squares).

Optimization. Unbounded Levenberg–Marquardt least squares (scipy.optimize.least_squares, method lm) — analogue of QVTplus fminunc / the paper’s least-squares fit:

  • Initial guess: mean waveform across stations + PWV = 10 m/s.
  • No parameter bounds during the fit; CSV acceptance still requires \(0 < \mathrm{PWV} < 30\) m/s.

Acceptance. CSV written when accept_pwv() passes: \(0 < \mathrm{PWV} < 30\) m/s.

Fielding vs Bjornfoot. Fielding estimates pairwise delays then regresses; Bjornfoot fits one global template + PWV. Both share \(\Delta t\), distances, and area weights; they can disagree when delays are noisy or waveforms poorly aligned.

Code: bjornfoot_prepare_waveforms(), pwvest3_share_cost(), pwv_bjornfoot_optimize(), accept_pwv() in hemodynamics.py.

Stage 7 operates on eICAB multilabel TOF masks, not 4D-flow. Centerlines are generated internally (skeleton → VMTK), independent of stage 3.

Tortuosity \(T_{dm}\)\(T_{dm} = L / C\)

Code: tortuosity_dm() in src/nvitk/measure/morpho/metrics.py; analyze_centerline_poly() in centerlines.py.

B.2 Curvature and torsion

Discrete curvature at interior point \(i\):

\[ \kappa_i = \frac{\|(\mathbf{p}_i-\mathbf{p}_{i-1}) \times (\mathbf{p}_{i+1}-\mathbf{p}_{i-1})\|}{\|\mathbf{p}_i-\mathbf{p}_{i-1}\|\,\|\mathbf{p}_{i+1}-\mathbf{p}_{i-1}\|\,\|\mathbf{p}_{i+1}-\mathbf{p}_i\|} \]

Code: discrete_curvature(), discrete_torsion() in metrics.py.

B.3 Radius and taper reference

Radius \(r(s)\) from cross-section or maximum inscribed sphere (MIS) EDT (default for stenosis/enlargement: RADIUS_SOURCE_FOR_CALIBER_DETECTION = "maximum_inscribed_sphere").

Taper reference \(r_{\text{ref}}(s)\):

  1. 1. Exclude siphon regions (\(\kappa \geq 0.10\) mm⁻¹, dilated 5 mm).
  2. 2. Exclude vessel ends (2 mm stenosis / 3 mm enlargement).
  3. 3. Sliding window (20 mm) 85th percentile, smoothed (4 mm).
  4. 4. Optional two-pass iterative refit excluding detected lesions.
  5. 5. Enforce non-increasing reference (PAVA).

Code: caliber.py — _compute_vessel_taper(), compute_siphon_mask().

B.4 Stenosis and enlargement

Stenosis percent:

\[ \text{Stenosis\%}(s) = \left(1 - \frac{r(s)}{r_{\text{ref}}(s)}\right)\times 100 \]

Default threshold 10%, min segment 3 mm, end exclusion 2 mm.

Enlargement percent:

\[ \text{Enlargement\%}(s) = \left(\frac{r(s)}{r_{\text{ref}}(s)} - 1\right)\times 100 \]

Default threshold 10%, min segment 5 mm, end exclusion 3 mm.

Code: stenosis_raw_percent(), detect_stenosis_segments(), enlargement_pointwise() in caliber.py.

Part C — Venous region labeling (stages 3–5)

Venous labeling is geometric classification, not a hemodynamic metric. Fixed label IDs 31–34 in src/nvitk/pipes/qvtpy/labels.py.

IDName

C.1 Venous foreground (stage 3)

  1. 1. CD segmentation: sliding threshold on ComplexDifference_3D (up_thresh=0.8, shift_hm=True).
  2. 2. Spatial mask: superior Y-third of volume.
  3. 3. Optional brain mask from TotalSegmentator on Angiography_3D.
  4. 4. Area-opening cleanup (min_fraction=0.005).

Code: binary_vessel_segment_cd() in flow_volume_masks.py; stage3_centerline.py.

C.2 Skeleton and assignment

  1. 1. Skeletonize each connected component.
  2. 2. Split at all junction voxels.
  3. 3. Keep polylines with ≥ min_branch_points (12 default).
  4. 4. Greedy assignment in order SSSV → STRV → LTSV → RTSV; score ≥ 0.05.

Confluence center (weighted centroid, RAS coordinates):

\[ w_k = \exp(0.15\,(si_k - \text{median}(si))) \cdot \exp(-0.1\,(ap_k - \min(ap))) \]

Branch score (example SSSV):

\[ S = L_{\text{score}}\left(0.35\cdot\text{midline} + 0.25\cdot\text{superior} + 0.2\cdot|\hat{d}_{SI}| + 0.2\cdot\text{toward\_conf}\right) \]

RAS score and legacy voxel-index score are both computed; max(RAS, legacy) wins.

Code: venous_heuristics.py — assign_venous_branches(), _score_branch_ras().

C.3 Downstream (stages 4–5)

Stage 4: Local lsthr threshold per venous label; largest CC kept. Region growing skipped for labels 31–34 (QVTPY_RG_SKIP_LABEL_IDS). Venous centerlines re-imported from stage 3.

Stage 5: One LOC per sinus at arc-length midpoint; SSSV/STRV swap validation via direction alignment to \([0,1,1]\).

Code: stage4_4dflow_segmentation.py, loc_selection.py (select_venous_locs).
