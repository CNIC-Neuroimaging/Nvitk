# Changelog - Cellpose3 Cyto3

## [v1.0.0] - 2025-10-14

### Added
- Initial version of Cellpose3 cyto3 model
- Pretrained weights from official Cellpose3 release
- Support for 2D and 3D cell segmentation

### Notes
- Model downloaded from official Cellpose repository
- Tested with Cellpose library v3.x
- Recommended for general-purpose cell segmentation tasks

### Known Limitations
- Performance may vary on highly specialized cell types
- Requires Cellpose library for inference
- GPU recommended for large batches
